# Person naming (人名) — naming humans

Loaded from `SKILL.md` Stage 1 when the object is a person's name (baby, pen name, 艺名). This is a different discipline from brand naming: the "user" doesn't choose the name, carries it for eighty years, and it must serve every context from kindergarten roll call to a résumé to international travel. Substitute this rulebook for the brand-oriented checks in Stages 2–4; keep the four-stage rhythm.

## Stage differences

### Positioning (Stage 1 for persons)

Ask and record: surname 姓氏 (mandated — every check below runs on the FULL name), **birth date/time** (for deriving 八字喜用神 — always with the "以专业排盘核对" caveat — or accept the family's stated 喜用神/五行所缺), family generational character 字辈 if practiced, any other 八字 or clan customs the family observes, gender preference or neutrality, and the parents' aspiration in one sentence ("知书达理" / "平安健康" / "明亮开阔").

**Customs stance**: treat 八字五行/字辈/族谱 as *given constraints to satisfy*, the same way a brand brief's taboo list is satisfied — apply them without endorsing or promoting them, and without dismissing them either.

### Ideation (Stage 2 for persons)

Territory mapping still applies, but the territories are different: 出处 (classical sources), 意象 (nature, seasons, virtues), 音韵 (sound-first coining), and 时令 (birth season/time). Mine 诗经/楚辞/唐诗宋词/成语 for sourced names with real, checkable meaning — a source adds dignity only if the average person can feel it; obscure allusions read as homework.

### Validation (Stage 3 for persons) — the full-name checklist

Score on these in place of the brand dimensions:

1. **全名谐音 sweep**: read the full name aloud as a sentence — 史珍香/杜子腾-class homophone disasters are the #1 failure. Check in Mandarin AND any dialect the family speaks (粤语/闽南语 etc.), plus common English misreadings of the pinyin.
2. **声调曲线**: full name should have tonal movement; three identical tones in a row drone. Watch the surname-name boundary for 连读 (e.g., 名字 that merges into the surname).
3. **多音字 & 生僻字**: no polyphonic characters (teacher will guess wrong at roll call); no characters that break 户籍/银行/值机 systems. If a character isn't in 通用规范汉字表一级字, drop it.
4. **时代撞名**: every era stamp its bearers — 建国/伟 (50s), 丽/娟 (60-70s), 梓涵/子轩/浩宇 (2010s-20s). Check against current top-popularity waves (公安部姓名报告 patterns) and offer both mainstream-comfort and low-collision options with the trade-off stated.
5. **生命周期 fit**: must work at age 5 (playground), 25 (interview), 60 (tombstone). Over-cute 叠字 or overly archaic characters both fail this.
6. **国际拼音**: if the family expects international life, the pinyin must survive English mouths (X/Q/Zh/J- initials and -ing/-ang confusion); test the standalone given-name pinyin as an email handle.
7. **公众人物重名**: flag significant collisions (sharing a name with a notorious or extremely famous figure shapes first impressions you didn't choose).
8. **五行层 (mandatory for persons)**: grade the full name's element chain against the 喜用神 per `references/wuxing-scoring.md` — traditional practice centers this for person names, so the 五行 line for a person name carries the 生克 reasoning (e.g. 水生木 ✓ 补喜用), not just stars.

### Collision & delivery (Stage 4 for persons)

- Uniqueness check: recommend the family use the official 全国同名查询 (公安一网通办/政务服务 App) for real duplicate counts — the agent cannot query it.
- Deliver: 5 candidates, each with meaning + source + full-name pinyin with tone marks + homophone-sweep result + era-collision estimate + the full-name 五行 grade against 喜用神 (with 生克 reasoning) + a one-line aspiration line. No.1 recommendation with reasoning.
- Never deliver a person name without having checked the full name ALL together — a beautiful 名 under an unlucky 姓 is a failed delivery.
